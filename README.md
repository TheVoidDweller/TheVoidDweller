## Featured project

### Road Geometric Design Toolkit

A free browser application for highway geometric design calculations, design checks and calculation reports, in Portuguese and English.

- **Horizontal geometry:** curves, spiral transitions, superelevation, lane widening and sight distance.
- **Vertical geometry:** grades, crest and sag curves, stopping sight distance, curve length and K value.
- **Speed-change lanes:** acceleration and deceleration lanes with a dimensioned conceptual layout.
- **Reporting:** calculation sheets with the manual item behind each value, a consolidated project calculation book and Excel export.
- **Verification:** worked examples that recalculate the tool's results by hand from the cited equations and tables.

The implemented references are Brazilian (DNIT manuals and an ARTESP option). The project page explains how they compare with the AASHTO Green Book.
